# Навигация по заданиям

> Файл показывает, где в итоговой версии проекта находятся реализации,
> относящиеся к заданиям практической работы.
> Некоторые классы, в частности `Ticket.java`, изменялись и дополнялись
> в процессе выполнения нескольких заданий, поэтому указанные файлы
> содержат их итоговую версию(из-за технических сложностей репозиторий был создан позже работы).

## Обязательная часть

| Задание | Что реализовано | Где искать |
|---|---|---|
| 1. Создание проекта и точки входа | Точка входа и запуск программы | `Main.java` |
| 2. Первая модель Ticket | Итоговая модель заявки | `Ticket.java` |
| 3. Инкапсуляция состояния заявки | Закрытые поля и методы работы с состоянием | `Ticket.java` |
| 4. Контроль допустимых переходов | Проверка переходов статусов | `Ticket.java` |
| 5. Enum вместо строк | Перечисление статусов | `TicketStatus.java`, `Ticket.java` |
| 6. Базовый класс User | Общая модель пользователя | `User.java` |
| 7. Наследование ролей | `Customer`, `SupportAgent`, `Administrator` | `Customer.java`, `SupportAgent.java`, `Administrator.java` |
| 8. Переопределение и полиморфизм | `performAction()` | `User.java`, классы-наследники |
| 9. Абстрактный User | Абстрактный класс и метод | `User.java` |
| 10. Интерфейс уведомлений | Интерфейс и реализации уведомлений | `NotificationService.java`, `ConsoleNotificationService.java` |
| 11. TicketService | Сервис работы с заявками и уведомлениями | `TicketService.java` |
| 12. Репозиторий заявок | Хранение и поиск заявок | `TicketRepository.java` |
