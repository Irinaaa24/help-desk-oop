# Практическая работа №1 - Help Desk

Учебный проект по дисциплине «Технологии и методы программирования».

Язык: Java 17  
Среда разработки: IntelliJ IDEA

## О проекте

Проект представляет собой консольную систему Help Desk для работы с заявками пользователей.

Основной сценарий заявки:

NEW → IN_PROGRESS → RESOLVED → CLOSED

В проекте реализованы обязательная часть практической работы,
дополнительные задания и творческое задание с использованием устройства `Device`.
